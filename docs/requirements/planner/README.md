# Planner requirements

What the planner system and its components promise.

| Document | Promises about | Verified |
|---|---|---|
| [checklists.md](checklists.md) | Each traveller's checklists on a trip, which only they see and tick, and their own templates, kept outside any trip, to start each from | Against the package alone, with a Before leaving checklist, under two device languages and time zones |
| [itinerary.md](itinerary.md) | How a trip's pencilled stretches and firm items are stored and changed | Against the package alone, with a trip through France, New York and Montreal, under two device time zones |
| [library.md](library.md) | Each traveller's library of checklist templates, kept online outside any trip, in a table of the online side's D1 database | Against the Worker, in Wrangler, with one traveller on several devices and another trying to reach their library |
| [pages.md](pages.md) | The pages of a trip, where travellers write up their research by hand | Against the package alone, with a trip through Chile, under two device languages and time zones |
| [planner.md](planner.md) | The trip planner: each trip's pencilled calendar, its firm dates, the countries it visits, its pages, and each traveller's checklists and templates | End to end, on a running system, with a trip through France, New York and Montreal |
| [trip-host.md](trip-host.md) | The copy of each trip held online, in a Durable Object of its own, which applies every change and keeps each traveller's devices up to date | Against the Worker, in Wrangler, with several devices on one trip |
