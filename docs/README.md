# The Itinero documentation

This folder is the workspace's documentation vault. Open it as a vault in Obsidian, or read it here
on GitHub. Both show the same files. How the vault is arranged, and which rules a checker enforces,
is [documentation-system.md](documentation-system.md). How the sentences inside each document are
written is [style.md](style.md).

## At the vault root

| Document | Holds |
|---|---|
| [documentation-system.md](documentation-system.md) | Where each kind of document lives, what shape it takes, and which rules are checked |
| [style.md](style.md) | How documents are written |
| [components.md](components.md) | The component registry: every system, component and concern, and the prefix each owns |
| [CHANGELOG.md](CHANGELOG.md) | What has been done, newest first, including each item of the live work list when it is finished |

## The trees

| Folder | Answers |
|---|---|
| [requirements/](requirements/README.md) | What each system, component and concern promises |
| [spec/](spec/README.md) | What each thing built in this workspace does, and how |
| [decisions/](decisions/README.md) | What was chosen, and why |
| [guides/](guides/README.md) | How to do one task, step by step |
| [roadmap/](roadmap/README.md) | The order each system's work happens in, and what was present at each step |
